# dyguard

抖音辅助插件，适用于 LSPosed/Xposed 环境，无桌面图标。

## 支持版本

- Android 9 及以上。
- 抖音 39.9.0（390901）、40.8.0（400801）；本次主要在 40.8.0 实机验证。
- 适配规则由云端签名下发，APK 不再内置版本规则。其他版本需有对应规则及客户端引擎支持。

## 功能

- 密友隐藏、长按临时显示、点按重新隐藏，支持切后台和锁屏自动隐藏。
- 过滤消息列表、搜索、转发选人、互动消息及相关联系人页面；同步处理相关未读和隐私名单人数。
- 密友来电隐藏与静音，新消息标题加粗和震动提醒；加粗程度、长按时长和点按次数可调。
- 防撤回，保留本机已收到的原文，自定义撤回提示。
- 图片去水印及图片、视频增强保存。
- 视频和短剧自动切换，支持播完切换、自定义秒数及广告倒计时；小开关支持拖动、记住位置和长按进入设置。
- 首页显示授权开始、到期时间和版本适配状态。

## 使用

安装后在 LSPosed 启用 dyguard，作用域勾选抖音，强制停止并重新打开抖音。在抖音搜索框输入 `#dy` 打开设置。

首次获取或更新云端适配规则后，按提示强制停止并重新打开抖音。已验签的规则会按抖音版本缓存；断网或更新失败时保留已有规则。首次没有缓存时需先联网获取配置。授权有效期与适配缓存分别校验。

覆盖安装新版后，同样强制停止并重新打开抖音。
