# dyguard

适配抖音 39.9.0 的 LSPosed/Xposed 模块，提供密友隐私管理、防撤回、图片与视频保存和自动播放。中文界面，无桌面图标。

## 使用条件

- 已可用的 LSPosed/Xposed 环境；Android 8.0 及以上。
- 当前适配抖音 39.9.0（版本代码 390901）。其他版本需对应适配，不承诺自动兼容。
- 在 LSPosed 启用 dyguard 并勾选抖音，强制停止并重新打开抖音。

## 打开设置

在抖音搜索框输入 `#dy`。首次按提示设置密码；可在设置中关闭设置密码验证。

## 功能

- 密友会话隐藏与临时显示，相关未读、转发和互动页面过滤。
- 可设置切后台、锁屏或离开聊天页后的自动隐藏；密友来电隐藏及静音。
- 密友新消息标题加粗、震动提醒。
- 保留本机已收到的撤回消息，自定义提示文案。
- 图片与视频保存，适用资源的去水印/增强保存。
- 播完或按自定义秒数切换下一条。视频页小开关可移动、记住位置，长按进入设置。
